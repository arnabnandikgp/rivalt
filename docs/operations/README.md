# Operations and validation

Use explicit local profiles, test assets and pinned artifacts. Default/devnet builds
do not activate the current account-centric canonical financial path. Earlier
successful devnet checks apply to their recorded implementation only.

- [Local development](local-development.md): exact tools, commands, demo and storage.
- [Deployment](deployment.md): identities, roles, maker kit, rotation, recovery/exit.
- [Validation](validation.md): choose relevant checks; actual qualified revisions,
  resource limits and remaining evidence boundaries.
- [Performance](performance.md): P39–P44 contention contract, workload methodology,
  executable access audit, immutable pre-Anchor-v2 baseline and RC2 comparison.
- [Architecture constraints](constraints.md): P50 source/provenance audit of inherited
  profile limits, operational assumptions and proposed priorities; not authority to
  change the current financial contracts.
- [Anchor v2 migration](anchor-v2-migration.md): accepted P45 contract and qualified P46/P47
  implementation; STATUS separates acceptance from integration.

| Change | Required reading/check family |
|---|---|
| Documentation only | Links, source paths, commands and current-vs-history claims |
| Account/ABI/refactor | Layout/discriminator/PDA/meta/error parity, generated SDK, isolated legacy Anchor, affected SBF paths |
| Financial transition | Independent literal/large-integer cases, actual compiled transition/rollback and relevant whole-account safety |
| Maker/pricing/router | Independent per-lot/math/optimality, authenticated quote parity, race/capacity/resource cases |
| Funding publisher | Independent input/report replay and separate on-chain authority/causality checks |
| Services/indexer | Actual Surfpool/RPC/WS/PostgreSQL, original-signature recovery and fresh replay |
| UI/wallet | Relevant browser signing, failure/reload/direct-exit checks; external wallets separately |

Do not run every historical suite before each PR. A source/ABI rebuild invalidates
artifact identity assumptions even when economics are intended unchanged. Tests
must match the change; hosted broad checks do not replace required integrated
acceptance, and old results do not qualify new paths.

Preserve ignored local raw evidence at its existing location. Track concise current
claims, exact pins and bounded regression fixtures; no per-run evidence documents,
JSON archives or uploads. Secrets stay in mode-0600 ignored configuration.

P15B independent-maker validation and P16B independent-review/funded-pilot readiness
remain Open. Continuous 24-hour endurance is Deferred. Production/funded deployment,
paid services, outreach/recruitment and external hedging need separate authorization.
