## Corrections, scoped checks and limits

- First trading attempts exposed harness assumptions: the public queue record
  intentionally omits signed wire, and separate RPC reads have different context
  slots. Corrected SQL original-byte lookup and economic comparison retain exact
  signed-message validation. Failed runs remain recorded in WORKLOG.
- Actual expired maker renewal rejected combined publication/sync with MakerBinding
  because transaction-wide writability violated the clearing config boundary.
  Separate immutable publication then finalized owner sync passes on `2767cdd`.
  Intermediate unsynchronized makers remain unavailable; no program constraint changed.
- Guard-only proof does not increment group sequence. Its expiry authority is now
  null, retaining unknown history and fee reservations. The focused regression
  passes; no signed R047 financial bytes change. Maker publication likewise cannot
  infer nonexecution from an unchanged registration epoch.
- Focused tests cover generated event authentication/projection, current funding
  and reservations, whole-account allocation, direct builders, ingress/expiry,
  worker authority/budgets, settlement/risk and deployment identities. Actual
  commands, counts and failures are in R042–R049. Typecheck and evidence policy pass.
  The shared allocator's independent 600-vector comparator and affected V1 wallet
  transport checks run where changed; no historical result is counted as new.
- Broad regression belongs to the scoped hosted workflow. Unchanged Rust/SBF/IDL,
  V1 integrated matrix, browser, devnet and endurance suites were not rerun for
  this service phase. CI results must be reported separately after publication.
- Whole-group sequences/certificates can contend with ongoing sampling/trading;
  busy-group exit progress, offer denominators and discovery latency remain P21B.
  Sampling cadence, source deadlines and risk checks are unchanged. Eight paid
  completed-recovery checks per epoch are an operational bound; workers cannot
  emergency-freeze, resume or reactivate cross without the existing authority.
- TP/SL, fractional ownership, transfers and netting retain P19/P20's explicit
  implementation acceptance. New service/browser paths must report their own
  coverage; this report does not label inherited protocol tests as fresh UI tests.
