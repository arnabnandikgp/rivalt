# Rivalt interface foundation

_Status: deferred_

A neutral light/dark theme is the temporary engineering choice for the authorized unattended P10 implementation. No final brand direction has been selected by the user. Shared CSS tokens govern surfaces, text, focus, spacing and semantic buy/sell/error colors. Typography uses the system sans and monospace stacks; no external font request or telemetry is needed.

The interface emphasizes actual BTC fills, separately labeled risk prices, funded cash and unpaid claims. Test assets and network identity remain visible. Future brand work may replace these tokens without changing transaction or accounting behavior.
